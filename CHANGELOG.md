## 1.0.0

- Initial release of `@conversantech/react-native-api-tracker`.
- Captured XMLHttpRequests and fetch network logs automatically.
- Interactive in-app console overlay for logging session statistics.
- Full details view for inspecting network request/response headers and bodies.
- Log searching, filtering, and export capabilities.
- Optional screen tracking via `@react-navigation/native` integration.
- Custom dropdown configurations to toggle logging active state.
